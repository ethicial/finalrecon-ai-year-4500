## 📦 Installation

### Requirements
- Python 3.6+
- `pip3`
- Linux / macOS / Windows (WSL recommended)

### Quick Install

```bash
# Step 1: Clone the repository
git clone https://github.com/ethicial/finalrecon-ai-year-4500.git

# Step 2: Navigate to the project directory
cd finalrecon-ai-year-4500

# Step 3: Install required dependencies
pip3 install -r requirements.txt
```

### requirements.txt

Make sure the following file exists in the project root:

```
requests>=2.25.0
urllib3>=1.26.0
```

## ⚙️ Factory Restart

The **Factory Restart** feature resets the server to its default state:

### Factory Restart Categories

| Category | Description |
|----------|-------------|
| **factory_reset** | `/factory-reset`, `/system/reset`, `/hard-reset`, `/restore-defaults` |
| **factory_restart** | `/factory-restart`, `/restart`, `/reboot`, `/shutdown`, `/power-cycle` |
| **system_clean** | `/system-clean`, `/clean`, `/purge`, `/wipe`, `/erase` |

### Usage

```bash
# Factory restart single server
python3 finalrecon-ai.py --url https://example.com --factory-restart

# Factory restart ALL servers
python3 finalrecon-ai.py --url https://example.com --factory-restart-all
```

### FACTORY RESET Output

